用自己的抖音 / 小红书账号听直播、回弹幕、做场控。

当前版本：**v1.1.0（双平台首发：抖音 + 小红书）**  
仓库仅提供安装包下载，**不公开源码**。  
国内用户优先从 Gitee 下载：[jiangbo/dy_live_tool](https://gitee.com/jiangbo/dy_live_tool)  
GitHub：[myhgjb666/dy_live_tool](https://github.com/myhgjb666/dy_live_tool)  
请使用自己的账号，只辅助自己有权操作的直播间。本软件不是抖音或小红书官方产品，请遵守平台规则与当地法律。

## 下载 Windows 安装包

到 Releases 下载：

- **Gitee（国内）**：https://gitee.com/jiangbo/dy_live_tool/releases  
  若附件为分卷压缩包（`.zip` + `.z01`），两文件放同一目录，用 7-Zip / Bandizip / WinRAR 打开 `.zip` 解压即可。

## 第一次使用

1. 用软件账号登录或注册（验证码为图片计算结果）。
2. 顶部选择平台（抖音 / 小红书），再用对应 App 扫码。
3. 粘贴直播间地址点「开始监听」，或点收藏一键开听；链接会自动识别所属平台。
4. 右上角「自动化设置」里配置回复、关注、定时、计数等。
