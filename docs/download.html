三、安装与首次运行

  1. 从上方渠道下载 LiveAssistant-v1.1.0.exe，建议放到一个固定目录（例如 D:\LiveAssistant\），后面配置和数据都会存在同目录下的 datas/ 文件夹里。
  2. 双击运行。若系统弹出「Windows 已保护你的电脑」提示，点击「更多信息」→「仍要运行」（原因见下方常见问题）。
  3. 首次打开会要求注册软件账号，完成后自动登录进入主界面。
  4. 点击登录按钮，用手机抖音 App 扫码完成抖音账号登录。
  5. 粘贴直播间地址点击「开始监听」，弹幕即会实时同屏显示。
  6. 打开右上角「自动化设置」配置关键字回复、欢迎感谢、定时弹幕与计数，或直接套用场景模板。

详细的分步配置说明（含每个页签的截图）请看 使用教程。

六、安装常见问题

提示「Windows 已保护你的电脑」，或者杀毒软件报风险

这是未做代码签名的小众 exe 被启发式规则误报的常见现象，不代表文件有问题。请先确认安装包来自本页给出的官方渠道、文件名与版本号一致，然后在安全软件中把软件目录加入信任列表，或选择「仍要运行」。如果下载来源无法确认，请删除文件重新从官方渠道下载。

双击没有任何反应 / 一闪而过

先确认系统是 64 位 Windows 10 或 11；再检查是否被杀毒软件静默拦截（查看隔离区）。若问题依旧，换一个目录重新解压运行，避免放在含中文或特殊符号过长的路径下（例如桌面深层文件夹）。

扫码登录时二维码不显示或一直加载

通常是电脑网络无法访问抖音，或防火墙拦截了软件的网络请求。请先检查代理 / 防火墙设置，再关闭软件重开一次。

换电脑后配置丢了

配置保存在软件目录的 datas/ 文件夹，换电脑时把整个软件目录一起拷贝过去即可。注意软件账号与设备绑定，换机后需要在后台重新绑定或续期。

Mac 能用吗？

当前版本只提供 Windows 客户端，暂不支持 macOS。Mac 用户可在虚拟机中运行，或关注后续版本说明。
